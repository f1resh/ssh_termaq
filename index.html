Everything in one window

Tabs, split panes and broadcast input

Open each server in a tab, split any tab into panes, and type into all of them at once when the same command has to run everywhere.

A file manager, not just a terminal

Every SSH session has an SFTP panel beside the terminal, and a two-pane file manager shows your computer and the server side by side. Drag files between them or to and from Explorer and Finder, watch the transfer queue, resume interrupted transfers, edit remote files in your own editor and keep folders in sync. No SFTP on the server? It falls back to SCP.

Find anything in a keystroke

The command palette finds sessions and commands as you type. Sessions live in folders with colours and notes, and every shortcut can be changed.

SFTP next to the shell

Browse, upload and download without leaving the terminal.

Key generator

Ed25519, RSA and ECDSA keys, saved as OpenSSH or PuTTY .ppk.

Themes

Built-in themes from Dracula to Solarized, plus your own colour schemes.

Safe by default

Host keys are checked on every connection, and saved passwords are encrypted by the operating system.

And everything else you expect

  • Protocols: SSH-2, Telnet, Rlogin, Raw TCP and serial ports
  • Sign-in: password, keys, two-factor (keyboard-interactive), Pageant and ssh-agent
  • Forwarding: local, remote and dynamic (SOCKS) ports, agent and X11 forwarding
  • Getting there: jump hosts, SOCKS, HTTP and Telnet proxies, proxy commands
  • Terminal: PuTTY's keyboard modes and character sets, find, zoom, copy on select
  • Links: ssh://, sftp://, scp:// and telnet:// open in SSHTermaq

Coming from PuTTY?

You don't start over. SSHTermaq reads what PuTTY already knows.

  • Imports your saved sessions, Default Settings and trusted host keys – from the registry, a .reg file or ~/.putty
  • Uses your .ppk keys (v2 and v3) and OpenSSH keys
  • Understands PuTTY's command line: -ssh, -P, -l, -i, -load, -L/-R/-D and more
  • Has PuTTY's settings, from keyboard modes to proxy options
  • Also imports hosts from your OpenSSH ~/.ssh/config

Questions

Is it really free?

Yes. SSHTermaq is open source under the MIT license: no price, no subscription, no account and no ads.

Where are my sessions stored?

On your computer only: in %APPDATA%\SSHTermaq on Windows and ~/Library/Application Support/SSHTermaq on macOS. On Windows a portable copy can keep everything next to the program instead.

Are my passwords safe?

Saving a password is optional. When you do, it is encrypted with the operating system's protection for your user account (Windows DPAPI, or a key kept in the macOS Keychain). Keys and agents are always the better choice, and both are supported.

Does it send anything anywhere?

No. SSHTermaq connects only to the servers you open, and has no telemetry or update pings. See the privacy policy.

Windows says "Windows protected your PC". Is that normal?

SmartScreen warns about programs it hasn't seen often yet. Choose More info › Run anyway. You can check the download against the release on GitHub, and the source code is public.

Which Mac download do I need?

Apple menu › About This Mac: a chip called "Apple M…" means Apple silicon; a processor called "Intel" means Intel.

Is there a Linux version?

Not yet. SSHTermaq runs on Windows and macOS today.

Where do I report a bug or ask for a feature?

On GitHub Issues.
